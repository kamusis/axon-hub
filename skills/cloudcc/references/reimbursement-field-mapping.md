# 报销 — 字段映射规则

## 发票字段 → 报销单字段

| 发票字段 | 报销单字段 | API名称 | 说明 |
|---------|------------|--------|------|
| 开票日期 | 费用发生起始日期 | qsrq | YYYY-MM-DD |
| 开票日期 | 费用发生结束日期 | jsrq | YYYY-MM-DD |
| 服务名称/货物名称 | 费用类型 | fylx | 需判断映射（见 reimbursement-expense-types.md） |
| 销售方名称 | 费用说明 | fysm | 推荐含发票号 |
| 价税合计/金额 | 报销金额 | bxje | 仅数字 |
| 发票号码 | 发票号 | fapiaohao | 有则填，无则留空 |
| 购买方名称 | （验证） | - | 验证是否为公司名称 |

## 费用说明格式规范

**格式：** `票据附件名称：票据说明内容`

```
{附件文件名}：{货物/服务名称}（{销售方名称}，发票号：{发票号码}）
```

示例：
- `加油发票.pdf：92#普通柴油（中油安徽安庆潜山开发区加油站，发票号：19825252）`
- `IMG_0601.jpg：*家用制冷器具*冰箱（济南兴旺达商贸有限公司，发票号：42074197）`
- `滴滴行程单.pdf：网约车服务费（北京小桔科技有限公司）`

特殊情况：
- 无发票号 → 省略"发票号：XXX"部分
- 无销售方 → 只写货物名称，如 `停车费.jpg：停车费`

## 报销金额取值规则

| 发票类型 | 取值位置 |
|---------|---------|
| 增值税专票 | 价税合计（右下角小写合计） |
| 增值税普票 | 小写合计 |
| 机打发票 | 小写合计或金额列总和 |

## 特殊字段处理

### 项目编号（xmmc）
- 有业务机会编号 → 填写
- 无 → 留空（默认报销到部门成本）

### 关联记录字段
- 销售活动编号（xshdbh）：选填
- 报工单（bgd）：选填
- 出差申请（ccsqv1）：选填
- 外派申请（wpgzsq）：选填

### 发票号（fapiaohao）
- 有发票 → 填写发票号码
- 无发票 → 留空

## invoices.json Schema

发票识别结果统一为 JSON 数组格式，作为 `reimbursement-fill-invoice.py` 的输入：

```json
{
  "$schema": "invoices.json",
  "type": "array",
  "items": {
    "type": "object",
    "required": ["qsrq", "jsrq", "bxlx", "fylx", "fysm", "bxje"],
    "properties": {
      "qsrq":      { "type": "string", "format": "date", "description": "费用起始日期 YYYY-MM-DD" },
      "jsrq":      { "type": "string", "format": "date", "description": "费用结束日期 YYYY-MM-DD" },
      "bxlx":      { "type": "string", "enum": ["销售费用","实施费用","售前费用","日常费用","办事处费用","市场培育费用","荣誉激励奖金","俱乐部活动费用"] },
      "fylx":      { "type": "string", "description": "费用类型，必须从系统允许值中选择" },
      "fysm":      { "type": "string", "description": "费用说明，格式：{附件文件名}：{货物名称}（{销售方}，发票号：{XXX}）" },
      "bxje":      { "type": "number", "minimum": 0.01, "description": "报销金额，纯数字" },
      "fapiaohao": { "type": "string", "description": "发票号码，无则空字符串" },
      "xmmc":      { "type": "string", "description": "项目编号（业务机会），选填" },
      "xshdbh":    { "type": "string", "description": "销售活动编号，选填" },
      "bgd":       { "type": "string", "description": "报工单编号，选填" },
      "ccsqv1":    { "type": "string", "description": "出差申请编号，选填" },
      "wpgzsq":    { "type": "string", "description": "外派申请编号，选填" }
    }
  }
}
```

**注意：** 选填字段无值时传空字符串 `""`，不要省略字段。
