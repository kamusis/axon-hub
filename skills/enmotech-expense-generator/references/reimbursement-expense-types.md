## 判断流程

```
读取发票货物/服务名称
    │
    ├── 含"汽油/柴油/加油/车用油/92#/95#" → 差旅费-其他交通费 → 日常费用
    ├── 含"停车/过路/高速/ETC/通行费" → 差旅费-其他交通费 → 日常费用
    ├── 含"租车/代驾" → 差旅费-其他交通费 → 日常费用
    ├── 含"地铁/公交/出租/网约车/客运服务" → 市内交通费 → 日常费用
    ├── 含"机票/飞机票/航空运输" → 差旅费-机票 → 销售费用
    ├── 含"火车/高铁/动车/铁路" → 差旅费-火车票 → 销售费用
    ├── 含"住宿/酒店/宾馆/民宿" → 差旅费-住宿 → 销售费用
    ├── 含"餐饮/宴请/餐费" → 招待费 → 销售费用
    ├── 含"办公/文具/耗材/碳粉" → 办公耗材 → 日常费用
    └── 其他 → 根据最佳匹配选择（优先匹配更具体的关键词）
```
